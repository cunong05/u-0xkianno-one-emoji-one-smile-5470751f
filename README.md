## Why "😊"?

It's the warmest, friendliest smile in the set — soft closed eyes and a gentle upturned mouth, the face of someone genuinely glad to see you. No teeth, no wink, no joke to decode: just a calm, open smile. It reads instantly in every language and every age group, and it's the face people picture when they think of someone smiling back at them. Fresh enough to stand out from the obvious 😀/😄, yet everyone reads it in a blink.

## How it works

`main.ts` (Node 22, stdlib only, no network) writes exactly one emoji — `😊`, 1 code point, 4 bytes, no trailing newline — to `/output/entry.txt`, after a gate that the entry is exactly one Unicode code point with no whitespace.

## Run it

```sh
node main.ts
```

Then check the entry:

```sh
cat /output/entry.txt   # 😊
```
